# grant-calculator
a calculator web app to find out if you ~~worked enough~~ have enough hours to get your wanted [OBJECT] based on the grant you're using!
this is a very simple but very helpful (since i do not like math, or having to pop up my scientific calculator everytime) project, and hopefully it'll be helpful to you! or not /shrug

## Usage
- input your grant's rate;
- manipulate either:
  - your target price;
  - you hours you need (or have);
  - the stacks of grants you need (or have);

## Setup
this project is as like any nuxtjs project, as seen:
### run
`bun run dev`

... and it should be at localhost:3000

### build
`bun run build`

see https://nuxt.com/docs/4.x/api/commands/build for more details
